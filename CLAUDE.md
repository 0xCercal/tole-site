## Project

Web application using **Node.js** and **React**. Framework (Vite, Next.js, etc.) to be defined during initialization.

## Common Commands

Once the project is initialized, these npm scripts are expected:

```bash
npm install          # Install dependencies
npm run dev          # Start development server
npm run build        # Build for production
npm test             # Run tests
npm run lint         # Lint code
```

Exact commands may vary depending on the chosen framework. Check `package.json` scripts for the current definitions.
